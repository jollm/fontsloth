#+TITLE: Test font fixtures

These fonts are checked in so the test suite is deterministic and does
not depend on fonts installed on the machine.

Set =FONTSLOTH_TEST_FONT_DIR= to use a different directory instead.

* Synthetic fixtures

Generated by =generate.py= (requires fontTools, a test-time-only
dependency):

#+begin_src shell
python3 test/fonts/generate.py
#+end_src

| File                   | Contents                                             |
|------------------------+------------------------------------------------------|
| =fontsloth-test.ttf=   | TrueType: simple and composite glyf, cmap 4 and 12   |
| =fontsloth-test.otf=   | CFF1: cubic outlines, same cmap                        |
| =fontsloth-test.woff=  | WOFF1 wrapping =fontsloth-test.ttf=                   |
| =fontsloth-test-vf.ttf= | TrueType with an fvar wght axis and two instances    |

The synthetic fonts are original to this project and carry the same
license as fontsloth.

* IBM Plex Serif subset

=IBMPlexSerif-Regular-subset.otf= is a subset of IBM Plex Serif
Regular 3.001, used for CFF and GPOS/kern tests. It is redistributed
under the SIL Open Font License 1.1; see =OFL.txt=.

Source: =IBMPlexSerif-Regular.otf= from the IBM Plex project
(https://github.com/IBM/plex).

Regenerate with:

#+begin_src shell
pyftsubset IBMPlexSerif-Regular.otf \
  --output-file=test/fonts/IBMPlexSerif-Regular-subset.otf \
  --unicodes='U+0020-007E,U+0391-03C9,U+2018-201D,U+2013-2014' \
  --layout-features='kern' \
  --name-IDs='*' --name-legacy --name-languages='*' \
  --glyph-names --notdef-outline --recommended-glyphs
#+end_src

The subset intentionally keeps the ASCII and Greek ranges plus the
=kern= feature: this reproduces the GPOS class-definition precedence
case that =fontsloth-otf-typo-test= checks.
